## Introducción

Las ecuaciones diferenciales son una valiosa herramienta de las matemáticas que nos permite modelar fenómenos de ámbitos como la física, la ingeniería, la economía y las ciencias naturales. En muchos casos, obtener una solución resulta complejo o incluso imposible, por lo que es necesario recurrir a métodos gráficos que nos permitan entender  el comportamiento de las soluciones.

Uno de estos métodos es el **campo de pendientes**, una representación gráfica que muestra la dirección de la pendiente de las posibles curvas solución en cada punto del plano. A partir de esta información es posible ver características del comportamiento de las soluciones, estimar trayectorias y analizar la existencia y unicidad de las curvas solución sin tener que resolver explícitamente la ecuación diferencial.

En el desarrollo de esta guia estudiamos el concepto de **curvas solución mediante el campo de pendientes**, aprendiendo a interpretar los diagramas, reconocer cómo evolucionan las soluciones para diferentes problemas de valor inicial (PVI) y comprender la relación entre la ecuación diferencial y el comportamiento de sus soluciones.
